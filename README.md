# Aukro Eshop

**Demo:** https://aukro-eshop.vercel.app/

## Technológie

- Angular 21 (standalone komponenty, Signals, OnPush)
- Angular Material 21
- Tailwind CSS 4
- TypeScript 5.9
- Vitest (unit testy)
- Playwright (E2E testy)
- ESLint 10

## Spuštění

```bash
npm install
npm start
```

## Testy

```bash
# Unit testy
npm test

# E2E testy (vyžaduje bežiaci dev server)
npx playwright test
```

## Build

```bash
npm run build
```
